## Overview
This project analyzes rooftop solar potential in Toronto using
exploratory data analysis, machine learning, and geospatial visualization.

## Tools & Technologies
- Python (Pandas, Scikit-learn, Matplotlib)
- Google Colab
- Power BI
- Kepler.gl

## Key Questions
- What is the typical size of rooftop solar systems?
- How much electricity do they generate?
- Are they economically viable?
- Where are high-impact solar rooftops located?

## Machine Learning
- Linear Regression
- Random Forest Regression
- Predicts annual electricity generation from system size

## Geospatial Analysis
- Interactive map of solar rooftops
- Colored by GHG reduction

## Outputs
- Power BI dashboard
- CSV prediction files
- ML prediction examples
